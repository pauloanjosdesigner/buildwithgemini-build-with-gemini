# My agent: Color Guide for Designers
One-liner: A conversational color guide agent that helps UI/UX and visual designers generate, audit, and preview color palettes with a collection of curated color themes.

Tool coverage:
- Memory: Remembers brand style rules, contrast compliance targets (AA/AAA), and favorite design systems.
- Tools: Generate color harmonies, calculate WCAG contrast ratios, read and save color palettes to Firestore.
- Catalog/UI: Collection of color palettes rendered as swatch cards and token tables.
- Image gen: Visual preview of UI component mockups styled with the chosen palette.
- Sandbox: Contrast ratio math and OKLCH/RGB/HEX color space conversions.
